# Quickstart: Phase 1 In-Memory Todo Application

This guide provides instructions on how to run the application.

## Prerequisites

- Python 3.13+

## Running the Application

1.  Navigate to the root directory of the project.
2.  Run the main application file from the `src` directory:

    ```bash
    python src/main.py
    ```

3.  The application will start and display a menu of options in the console. Follow the on-screen prompts to interact with the Todo list.
